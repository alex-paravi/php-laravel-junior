## День 1 — 22 октября 2026: PHP Core

### Типы и неявное приведение

PHP может неявно преобразовывать типы, но в прикладном коде лучше не полагаться на это без необходимости.

```php
echo '15' + 5;   // 20: строка преобразована в число
echo '15' . 5;   // '155': конкатенация строк
echo true + 0;   // 1
echo (string) null; // ''
```

Для сравнения типов и значений обычно используй строгое сравнение: `===` и `!==`.

```php
0 == false;   // true
0 === false;  // false
```

### Null coalescing: `??`

Оператор `??` берёт правое значение, только если левое не существует или равно `null`. Значения `false`, `0` и `''` при этом сохраняются.

```php
$data = ['name' => '', 'confirmed' => false];

$name = $data['name'] ?? 'Unknown';          // ''
$confirmed = $data['confirmed'] ?? true;     // false
$email = $data['email'] ?? 'no_email';       // 'no_email'
```

Не путать с `?:`: «элвис»-оператор считает ложными также `false`, `0`, `''`, `[]`.

### Аргументы функций и объекты

Скалярные значения и массивы передаются в функцию по значению с copy-on-write: изменение локальной переменной не меняет исходную. Ссылка `&` позволяет изменить переменную вызывающего кода.

```php
function increase(int &$value): void
{
    $value += 5;
}

$total = 15;
increase($total); // $total === 20
```

Объектная переменная содержит идентификатор объекта. Если изменить его свойство внутри функции, тот же объект будет изменён снаружи. Но переназначение параметра на новый объект не заменяет исходную переменную вызывающего кода.

```php
function rename(User $user): void { $user->name = 'Ivan'; }
function replace(User $user): void { $user = new User('Petr'); }
```

## День 2 — 23 октября 2026: массивы, объекты, области видимости

### Массивы и ключи

PHP-массив — упорядоченная хеш-таблица: ключи могут быть целыми числами или строками. «Индексированный» и «ассоциативный» — удобные названия, но технически это один тип `array`.

```php
$names = ['Alex', 'Maria'];           // ключи 0, 1
$user = ['name' => 'Ivan', 'age' => 25]; // строковые ключи
```

При добавлении через `[]` PHP выбирает следующий автоматический целочисленный ключ — обычно на единицу больше наибольшего уже использованного неотрицательного integer-ключа. Это не обязательно «длина массива».

```php
$names = [2 => 'Alex'];
$names[] = 'Maria';  // ключ 3
$names[0] = 'Petr'; // не влияет на элемент с ключом 2
```

### Проверка и удаление ключей

```php
$data = ['name' => null, 'city' => ''];

isset($data['name']);           // false: null считается отсутствующим
array_key_exists('name', $data); // true: ключ есть
empty($data['city']);           // true: пустая строка — «пустое» значение
unset($data['city']);           // удаляет ключ
```

`isset()` удобно для «существует и не null», `array_key_exists()` — когда важно отличить ключ со значением `null` от отсутствующего. `empty()` возвращает `true` для отсутствующего ключа, `null`, `false`, `0`, `'0'`, `''` и `[]`.

### `foreach` и ссылки

```php
foreach ($names as $key => $name) {
    echo "$key: $name\n";
}

foreach ($names as &$name) {
    $name = strtoupper($name);
}
unset($name); // обязательно разорвать ссылку на последний элемент
```

Без `&` переменная цикла — значение элемента. С `&` она остаётся ссылкой на последний элемент и после цикла; последующий `foreach` или присваивание может случайно изменить этот элемент. Поэтому после `foreach (... as &$value)` всегда делаем `unset($value)`.

### `clone`, shallow clone и `__clone()`

`clone` создаёт **новый объект верхнего уровня**. Его простые свойства копируются отдельно. Но вложенные объекты в свойствах первоначально остаются общими: это поверхностное (shallow) клонирование.

```php
class Address { public string $city = 'Moscow'; }
class User {
    public string $name = 'Alex';
    public Address $address;
    public function __construct() { $this->address = new Address(); }
}

$first = new User();
$second = clone $first;
$second->name = 'Ivan';            // $first->name остаётся 'Alex'
$second->address->city = 'Samara'; // изменит и $first->address->city
```

Чтобы сделать независимой вложенную часть, реализуй `__clone()` и клонируй вложенный объект вручную.

```php
class User {
    public Address $address;
    public function __clone()
    {
        $this->address = clone $this->address;
    }
}
```

### `global` и `static`

Локальные переменные функции не видят глобальные автоматически. `global` подключает глобальную переменную, но в прикладном коде чаще предпочтительнее передавать данные аргументом.

`static` локальная переменная создаётся один раз и сохраняет значение между вызовами функции.

```php
$count = 10;
function incrementGlobal(): void {
    global $count;
    $count++;
}
function nextNumber(): int {
    static $number = 0;
    return ++$number;
}
```

### Замыкания и `use`

Замыкание (closure) — анонимная функция, которую можно сохранить в переменную или передать другой функции. Локальные переменные извне не видны ей автоматически: их надо явно захватить через `use`.

```php
$rate = 2;
$byValue = function (int $value) use ($rate): int {
    return $value * $rate;
};
$byReference = function (int $value) use (&$rate): int {
    return $value * $rate;
};

$rate = 5;
$byValue(10);     // 20: захвачено значение 2
$byReference(10); // 50: читается текущее значение 5
```

Захват по значению фиксирует значение на момент создания замыкания. Захват по ссылке связывает замыкание с самой переменной и видит её последующие изменения.

### `array_map()` и скидки

`array_map()` создаёт новый массив, применяя callback к каждому элементу; исходный массив не меняется. Внешнюю скидку callback получает через `use`.

```php
$prices = [100, 200, 300, 400];
$discount = 10;

$discounted = array_map(
    function (int $price) use ($discount): float {
        return $price * (1 - $discount / 100);
    },
    $prices,
);
// [90.0, 180.0, 270.0, 360.0]
```

Нюанс: выражение со скидкой обычно даёт `float`, даже если результат выглядит целым. Поэтому тип возврата `int` способен неявно отбросить дробную часть (при обычной типизации), например `99 * 0.9` станет `89` вместо `89.1`. Для денег обычно используют целые минимальные единицы (копейки/центы) и явно задают правила округления.

```php
$priceCents = 9_999;
$discountPercent = 10;
$discountedCents = (int) round($priceCents * (100 - $discountPercent) / 100);
// 8999: 89,99 в валютных единицах
```
